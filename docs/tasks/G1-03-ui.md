## Workspace wiring (implemented, not live-verified)

Changed paths (uncommitted on `build/g1-session-media`, base 7d6ff43):

- `lib/session/api-client.ts` (new): `startSession(durationSeconds, idempotencyKey = crypto.randomUUID())`, `markConnected(id)`, `endSession(id, reason, { keepalive })`. Same-origin JSON POSTs, `cache: "no-store"`. Success bodies parse with `startResponseSchema`/`sessionResponseSchema`; error bodies with `errorSchema`. Failures throw `SessionClientError { code, status, retryable, sessionId }`; `code` is an `ErrorCode` or client-only `NETWORK`/`MALFORMED_RESPONSE`. Nothing is logged.
- `app/practice/practice-workspace.tsx` (new, client): orchestrates the real call using `createDailyController` from `lib/media/daily-controller.ts`. No mock media.
- `app/practice/page.tsx`: same server identity check; renders `PracticeWorkspace`.
- `app/practice/workspace-preview.tsx`: deleted (sign-out moved into the workspace).
- `tests/unit/api-client.test.ts` (new).
- `components/presentation/**`: unchanged. "End previous practice", "Retry closing session", and "Back to setup" render as workspace buttons outside the presentation components.

State machine (`phaseRef` is authoritative; React state mirrors it for rendering):

- `setup` → Start (one idempotency key per click; `startingRef` blocks double-start) → `startSession(180)`. `SESSION_ACTIVE` with `session_id` shows "A previous practice is still open" and an "End previous practice" button (`endSession(id, "user")`); Start stays disabled until that succeeds. `UNAUTHENTICATED` is treated as auth loss. Other errors show the server's safe message.
- `connecting`: controller created with an attempt number; events from an older attempt are dropped. Remote stream renders in `<video autoPlay playsInline>` (unmuted; the stream carries counterpart audio and video), local preview in `<video muted playsInline>`.
- `ready` event → `live` once, `markConnected` once (an `SESSION_EXPIRED` reply interrupts), elapsed timer starts; at 180 s it ends with `time_limit`.
- `failed` / `remote-left` / `connect()` rejection → `interrupted` with a plain message; server end with `connection_failure`.
- End (`connecting`/`live`/`interrupted`) → `controller.end()` fires without awaiting, streams cleared, phase `ended`, then `endSession(id, "user")`. The status text reflects only the returned `cleanup` (`confirmed` / `pending` / `unresolved` / `not_started`) or "couldn't reach the server". A retry button re-sends the end for anything except `confirmed`.
- Mute calls `controller.setMuted` and is labelled mute; the presentation keeps the "not paused" note. Camera starts off; a denied camera shows a note and the call continues.
- Teardown without awaiting the network: unmount and `pagehide` call `endSession(..., { keepalive: true })` with `navigation`. Supabase `SIGNED_OUT` releases media, calls `endSession("auth_loss", keepalive)`, clears transient messages, and routes to `/auth/sign-in`. The Sign out button releases media first, then awaits `endSession("auth_loss")` (errors ignored) while the auth cookie is still valid, then signs out. A start response that arrives after teardown is ended immediately.
